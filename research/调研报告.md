# 调研报告：GitHub 上有没有「模拟鱼漂 / 台钓」的游戏（含 HTML 网页版）

> 调研时间：2026-11-23 17:15–17:45（Asia/Shanghai）
> 方法：GitHub Search API 多轮关键词（中/英/日）+ 仓库源码字节级抽查 + 站外（B站/知乎/掘金/itch 类站点）交叉检索 + 全部在线地址实测 HTTP 状态码
> 判定口径：**「符合」= 浮漂/漂尾可视化，且漂相动作直接决定提竿成败（含早提/晚提惩罚），或包含调漂（调目/钓目/找底）**；只有「抛竿→等几秒→点击收杆」的记为「沾边」。
> 明细见同目录 `repos.md`（GitHub 仓库实证）与 `web.md`（站外线索）。

---

## 一、先给结论

**GitHub 上没有「专门模拟鱼漂读漂相 / 台钓调漂」的完整可玩游戏。** 这个细分方向在开源世界是「机制碎片化」：

| 台钓的组成部分 | GitHub 开源现状 |
|---|---|
| 调漂（半水调目 → 重铅找底 → 钓目）、目数模型 | 有，但只存在于**没有鱼的交互教学模拟器**里（ANT-CYJ/fishing-basic、a4215629/Fishing） |
| 浮漂可视化 + 咬钩信号 + 提竿时间窗 | 有，散落在若干**通用钓鱼小游戏**里（fishoria / tideline / first-person-fishing / 钓鱼佬） |
| 假口 / 小杂鱼试探 vs 真口 | 有，最细的实现在一个航海游戏子系统里（bobber-run） |
| 饵料雾化、窝子、找底、调钓联动、顿口/送漂/黑漂分类 | **几乎没有**（fishoria 只有打窝 groundbait） |
| 以上全部串成一个作品 | **未发现** |

一句话：**想玩「看漂提竿」，GitHub 上有几个能立刻开玩的；想玩「调漂」，只能开教学模拟器；想玩完整的台钓，没有现成的，得自己做。**

## 五、要自己做的话，哪些东西能直接抄

按「省多少工」排序：

1. **TIDELINE 的浮漂 + 咬钩系统**（MIT，可直接商用）——`src/gameplay/bobber.js`（浮漂缓动/下沉）、`src/gameplay/biteSystem.js`（nibble 假口 → 真口 → 窗口）、`config.js`（`hookWindowBase 1.05` / `nibbleChance 0.65`）。这是**最小可玩闭环**的最佳起点，几十行就能改出「任意时长窗口 + 早/晚惩罚」。
2. **bobber-run 的假口状态机**——`TEASES`（不同鱼种不同试探节奏）、`FAKE_OUT`（大沉+水花但无实感）、`strikeWindows`（perfect/普通两档 + 失误后放宽保底），是「小杂鱼闹窝 vs 真顿口」最好的现成设计。
3. **fishoria 的漂相参数**——`client/src/game/engine/entities/HookEntity.ts`（`rigType==='float'` 时按鱼兴趣驱动 `sinkY` 微顿、`isDiving` 出涟漪）与 `detection.config.ts`（`nibbleMultiplier`、`EARLY_HOOK`、`biteTimeout 3~7s`）。注意：**只能当参数/思路参考，license 不明（NOASSERTION）**。
4. **ANT-CYJ/fishing-basic 的调漂交互模型**——调四钓二、重铅找底、打窝三件套的「状态机 + 目数概念」，正好补上 TIDELINE 缺的那一半。
5. **缺的那块得自己写**：「半水调目 → 找底 → 钓目」的连续物理求解（浮漂浮力 = 铅坠 + 饵重 + 水线）目前**没有可复用的开源实现**，这正是「调漂」游戏化最难也最值钱的部分。

**建议的最小可行闭环**：调漂（调目/钓目）→ 饵料状态 → 漂相分类（小口/顿口/送漂/黑漂，各带不同图形与时长）→ 提竿窗口判定（含假口、早提空竿、晚提脱钩）→ 复盘。现有开源项目最多只覆盖其中 1–2 段。

## 六、调研局限（如实说明）

- **itch.io 从本机完全不可达**（直连与 `r.jina.ai` 代理均返回 000，与 Google 同样不通），而 itch 恰恰是最可能藏 float/bobber 小游戏的地方。建议有正常网络时补检：`https://itch.io/search?q=float+fishing`、`https://itch.io/games/tag-fishing`。
- GitHub **core API 未认证额度（60/小时）中途耗尽**，star/时间等元数据改走 search API 与 jsDelivr 交叉核对；`raw.githubusercontent.com` 后半程超时，故源码抽查用 jsDelivr CDN 完成（字节数均为实际下载）。
- 中文搜「钓鱼」大量命中**网络安全钓鱼攻击（phishing）**仓库与外挂脚本，本报告已剔除；`钓鱼 = phishing` 是这个方向的检索噪音主要来源。
- 「在线可玩」仅验证了 HTTP 200，未在真实浏览器里操作过（沙箱无 GUI），个别作品的实际手感需你亲自点开确认。
